## Et eksempel, du selv kan ændre

Et forbrug på **16 kWh/100 km** og en samlet elpris på **2 kr./kWh** giver **32 kr. i strøm pr. 100 km**. Det er et valgt regneeksempel. Bilens øvrige omkostninger er ikke med.

[Åbn eksemplet og brug dine egne tal](https://www.evberegn.dk/beregnere/pris-pr-km/#s=1&k=2&consumption=16&electricPrice=2).

På de selvstændige beregnersider kan du dele et link med dine indtastede tal eller printe resultatet. Gamle delte priser kan være forældede.

## Kilder og feedback

Beregnere viser konsekvensen af dine forudsætninger. Din elaftale, ladepris, købspris og faktiske kørsel kan afvige fra eksempler og registrerede bildata.

- [Om værktøjet, metoder og kilder](https://www.evberegn.dk/om/)
- [Rapportér en fejl eller et forslag](https://github.com/kfris08-hub/ev-beregner/issues)
- [Se projektets automatiske kontroller](https://github.com/kfris08-hub/ev-beregner/actions)

Dette repository indeholder kildekode og genererede sider til evberegn.dk. Bilmotiver har individuelle kilde- og licensoplysninger i projektets billeddata og på modelsiderne.
