# Illustrerede dialog-Reels

Kilde til tre forskellige 25–29 sekunders samtaler fra 23. november 2026. Den komplette selvstændige kildepakke samt færdige MP4-filer er leveret separat som samtale-serie-20261123.zip. Binære aktiver, stemmer og MP4-filer er ikke indlejret i denne GitHub-mappe.

Følg creative/REEL-RETNING-20261123.md og den kanoniske daily/DAILY-PLAN.json. Optagelser fra en hjemmeside er ikke standarden for nye Reels. Illustrationerne er originale, personerne fiktive, musik er original kodekomposition, og kontrollerede tekstlag lægges på i render.py.

To syntetiske danske stemmer, ingen nye HeyGen-job. Genskab fra accepterede lydfiler; kør ikke nye TTS-job ved hver eksport. Menneskelig gennemlytning er ikke udført, og mundbevægelser er illustrative. Ingen garanti for organisk rækkevidde. En mediefil eller produktionsplan er ikke en publiceringskvittering.
